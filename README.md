# SmartExpenseAgent

SmartExpenseAgent is a sequential pipeline designed to automate invoice processing in a business setting. It continuously monitors a professional mailbox for invoices received as email attachments. As soon as a new email arrives, the agent automatically determines whether it contains an invoice or not. If it does, it downloads the document and visually verifies that it is indeed an invoice using a specially trained computer vision model. Once this verification passes, key information is automatically extracted: vendor name, date, amounts, taxes, invoice number, and line items. An advanced language model (GPT-4o) then analyzes this data to correct formatting errors and classify the expense into the right category, such as SaaS, Travel, Office, IT, or Consulting Services. Each invoice then goes through a series of consistency checks, for example to verify that the amounts are correct or that the dates make sense. If an invoice is validated, it is automatically added to an Excel report organized by expense category, ready to be used by the accountant. If a problem occurs with a document, the system retries several times before, if necessary, notifying the accountant by email with details of the error. This entire process runs completely autonomously, without human intervention, and repeats automatically every ten minutes. The system also learns from its own work: every validated invoice feeds into a dataset that can later be used to improve the models. The main goal of the project is to save considerable time for accounting teams by eliminating manual invoice entry. It also aims to reduce human errors and ensure better traceability of every processed document. This project was developed as part of a Final Year Project (Master's in Applied Artificial Intelligence) at Ibn Zohr University. It was carried out in collaboration with NTT Data, in a real professional setting.
